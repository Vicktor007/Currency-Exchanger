# 💱 CurrencyExchanger

A springboot application that enables users to convert currencies using live exchange rate APIs. This project supports multiple data sources for currency exchange rates.

## 🌟 Features

- Integration with two external currency exchange APIs

- Error handling for API failures and connectivity issues

## 🧰 Technologies Used

- Java 21
- Springboot 3.5.6
- IntelliJ IDEA
- OpenExchange Api
- Fixer Api



## 🧪 Troubleshooting

- **API Requests Failing**: Check your internet connection or the API endpoints.
